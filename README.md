# 弾き語りカラオケメーカー

コード譜付き歌詞を音源に合わせてカラオケのようにワイプ表示し、16:9の音源付きMP4に書き出すWindowsアプリです。

従来のRhythmicaLyricsでは、ルビブロックを移るたびに入力モードがひらがなへ戻るため、英数字のコードを続けて入力しにくい課題がありました。本派生版では英数字の入力モードを維持できます。ルビをコード譜として使い、歌詞の好きな位置にコードや小節線を配置することで、タイムタグに合わせてワイプするコード付き歌詞動画を作成できます。

## ダウンロード・起動

1. [Releases](https://github.com/hummingtsukasa-star/humming-karaoke-maker/releases) から配布ZIPをダウンロードします。
2. ZIPを右クリックして「すべて展開」します。
3. 展開したフォルダー内の「弾き語りカラオケメーカー.exe」をダブルクリックします。

インストールは不要です。起動時はフォルダー内の他のファイルを移動・削除しないでください。

## 基本操作

- タイムタグ付き歌詞（.rlf / .lrc / .txt）と音源を読み込みます。
- RhythmicaLyricsのルビ機能で、歌詞の文字にコードを付けます。
- 「歌詞動画」から16:9プレビューを開き、音源付きMP4を書き出します。
- ワイプとスクロールは歌詞のタイムタグに従います。
